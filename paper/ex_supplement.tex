\section{Master Equation Matrix Reconstruction}
\label{subsec:matrix_reconstruction}

In adaptive state space methods for the chemical master equation, the active state set $\mathcal{S}(t)$ evolves dynamically through expansion and pruning operations. The standard approach reconstructs the generator matrix $\mathbf{A}(t)$ from scratch at each time step, requiring $O(|\mathcal{S}(t)|^2)$ operations to populate all matrix entries. However, many states persist across consecutive time steps, making full recomputation wasteful. Consider the temporal evolution of state sets: 
\begin{equation}
\mathcal{S}_{\text{old}} \xrightarrow{\text{expand}} \mathcal{S}_{\text{exp}} \xrightarrow{\text{prune}} \mathcal{S}_{\text{new}}.
\end{equation}
Typically, a significant fraction of states in $\mathcal{S}_{\text{new}}$ are retained from $\mathcal{S}_{\text{old}}$ (often 50--80\% in practice). The key insight is that transition rates between retained states remain unchanged, enabling substantial computational reuse.

Given the previous active state set $\mathcal{S}_{\text{old}}$ with associated generator matrix $\mathbf{A}_{\text{old}}$, and the current active state set $\mathcal{S}_{\text{new}}$, we partition states into disjoint subsets:
\begin{align}
\mathcal{O} &= \mathcal{S}_{\text{new}} \cap \mathcal{S}_{\text{old}} && \text{(retained states)}, \\
\mathcal{N} &= \mathcal{S}_{\text{new}} \setminus \mathcal{S}_{\text{old}} && \text{(newly added states)}, \\
\mathcal{R} &= \mathcal{S}_{\text{old}} \setminus \mathcal{S}_{\text{new}} && \text{(pruned states)}.
\end{align}
This partitioning enables the new generator matrix to be expressed in block form:
\begin{equation}
\mathbf{A}_{\text{new}} = \begin{bmatrix}
\mathbf{A}_{OO}^* & \mathbf{A}_{ON} \\
\mathbf{A}_{NO} & \mathbf{A}_{NN}
\end{bmatrix},
\end{equation}
where $\mathbf{A}_{OO}^*$ represents the updated retained block, and $\mathbf{A}_{ON}$, $\mathbf{A}_{NO}$, $\mathbf{A}_{NN}$ are newly computed transition blocks.The core efficiency gain comes from reusing the off-diagonal structure of the retained block:
\begin{equation}
\mathbf{A}_{OO}^{\text{off-diag}} = \mathbf{A}_{\text{old}}[\mathcal{I}_O, \mathcal{I}_O]^{\text{off-diag}},
\end{equation}
where $\mathcal{I}_O$ denotes the index mapping from retained states to their positions in $\mathbf{A}_{\text{old}}$. However, diagonal elements must be updated to maintain the generator property (zero column sums):
\begin{equation}
\mathbf{A}_{OO}^{ii} = \mathbf{A}_{\text{old}}^{ii} - \sum_{j \in \mathcal{N}} \mathbf{A}_{ON}^{ij} + \sum_{j \in \mathcal{R}} \mathbf{A}_{OR}^{ij}.
\end{equation}
This adjustment accounts for new outflows to $\mathcal{N}$ and removes outflows to pruned states $\mathcal{R}$. For computational efficiency, we employ the \texttt{expand\_backward} operation to identify feasible transitions. Instead of checking all $|\mathcal{S}_{\text{new}}|^2$ state pairs, we compute only necessary transition blocks. For each new state $s_n \in \mathcal{N}$, we find source states:
\begin{equation}
\text{sources}(s_n) = \{s \in \mathcal{S}_{\text{new}} : \exists k \text{ such that } s + \boldsymbol{\nu}_k = s_n\}.
\end{equation}
The \texttt{expand\_backward} operation leverages reaction stoichiometry to efficiently identify feasible source states, avoiding exhaustive enumeration.

\begin{algorithm}[H]
\caption{Efficient Master Equation Matrix Reconstruction}
\label{alg:matrix_reconstruction}
\begin{algorithmic}[1]
\REQUIRE Previous state set $\mathcal{S}_{\text{old}}$, previous matrix $\mathbf{A}_{\text{old}}$, current state set $\mathcal{S}_{\text{new}}$
\ENSURE Current generator matrix $\mathbf{A}_{\text{new}}$

\STATE Partition states: $\mathcal{O} = \mathcal{S}_{\text{new}} \cap \mathcal{S}_{\text{old}}$, $\mathcal{N} = \mathcal{S}_{\text{new}} \setminus \mathcal{S}_{\text{old}}$
\IF{$|\mathcal{N}| = 0$}
    \RETURN $\mathbf{A}_{\text{old}}$ \COMMENT{No new states}
\ENDIF

\STATE Initialize $\mathbf{A}_{\text{new}} \in \mathbb{R}^{|\mathcal{S}_{\text{new}}| \times |\mathcal{S}_{\text{new}}|}$ as sparse zero matrix
\STATE Create index mappings: $\mathcal{S}_{\text{new}} \rightarrow \{1, 2, \ldots, |\mathcal{S}_{\text{new}}|\}$
\STATE Extract and copy: $\mathbf{A}_{\text{new}}[\mathcal{I}_O, \mathcal{I}_O] = \mathbf{A}_{\text{old}}[\mathcal{I}_{O,\text{old}}, \mathcal{I}_{O,\text{old}}]$

\FOR{each $s_n \in \mathcal{N}$}
    \STATE $\text{sources} = \texttt{expand\_backward}(s_n, \text{model}) \cap \mathcal{S}_{\text{new}}$
    \FOR{each $s_{\text{src}} \in \text{sources}$}
        \STATE Compute transition rate: $\alpha = \text{propensity}(\boldsymbol{\nu}, s_{\text{src}})$
        \STATE Set: $\mathbf{A}_{\text{new}}[i_n, i_{\text{src}}] = \alpha$
    \ENDFOR
\ENDFOR

\FOR{each state $s \in \mathcal{S}_{\text{new}}$}
    \STATE $\text{outflow} = \sum_{k} \mathbb{I}_{s + \boldsymbol{\nu}_k \in \mathcal{S}_{\text{new}}} \cdot \text{propensity}(\boldsymbol{\nu}_k, s)$
    \STATE Set: $\mathbf{A}_{\text{new}}[i, i] = -\text{outflow}$
\ENDFOR

\RETURN $\mathbf{A}_{\text{new}}$
\end{algorithmic}
\end{algorithm}

The computational complexity of the standard approach is $O(|\mathcal{S}_{\text{new}}|^2)$. Our method reduces this by reusing the $O(|\mathcal{O}|^2)$ entries for retained states and computing only the $O(|\mathcal{N}| \cdot |\mathcal{S}_{\text{new}}|)$ entries involving new states. For typical scenarios where the overlap ratio $|\mathcal{O}|/|\mathcal{S}_{\text{new}}| \approx 0.7$, this yields substantial speedups. The propensity evaluation overhead is negligible compared to sparse matrix operations and does not significantly affect the overall complexity.


\subsection{Performance Evaluation of Matrix Reconstruction}

To evaluate the computational efficiency of the proposed reconstruction method, we benchmarked two approaches for constructing the master equation matrix during adaptive FSP simulations: (i) direct construction via \texttt{MasterEquation}, which builds the full matrix from scratch at each time step, and (ii) incremental reconstruction via \texttt{reconstruct\_MasterEquation}, which reuses matrix entries from overlapping states. Both methods were evaluated on three benchmark systems (Oregonator, ROBER, and toggle switch) using BenchmarkTools.jl~\cite{BenchmarkTools.jl-2016} with $10^4$ trials over 5 seconds of wall-clock time.

Figure~\ref{fig:benchmark} presents the performance comparison for the Oregonator model. Panel (a) shows the probability density functions of execution times using kernel density estimation with a logarithmic x-axis to capture the full range of timing variations. The direct construction method (solid line) exhibits a broad, right-skewed distribution centered near 19~ms, indicating high variability in execution time. The reconstruction method (dashed line) shows a sharper, narrower peak at approximately 1~ms, indicating more consistent performance across trials. The vertical dotted lines mark the median execution times: 19.2~ms for direct construction and 1.25~ms for reconstruction. Panel (b) displays the cumulative distribution functions (CDFs), which show the fraction of trials completed within a given time. The reconstruction method (dashed line) reaches 50\% cumulative probability at 1.25~ms, while the direct construction method (solid line) requires 19.2~ms to reach the same percentile (marked by the horizontal dotted line at 0.5). The CDF for reconstruction rises steeply between 0.5~ms and 3~ms, indicating that most trials complete within this narrow window. In contrast, the CDF for direct construction rises more gradually between 15~ms and 25~ms. By 20~ms, the reconstruction method has completed nearly all trials ($>99\%$), while direct construction has completed only about half.

The 15-fold performance improvement is explained by the high overlap between consecutive state spaces in the Oregonator system. The overlap fraction, defined as $|\mathcal{S}_t \cap \mathcal{S}_{\text{old}}| / |\mathcal{S}_t|$, typically exceeds 0.7--0.9 during the simulation, meaning that 70--90\% of states are shared between consecutive time steps. The reconstruction method exploits this overlap by copying existing matrix entries rather than recomputing them. For a state space of size $|\mathcal{S}| \approx 200$--1000, reusing 80\% of matrix entries reduces the number of entries that must be computed from $\sim$1000 to $\sim$200 per time step. The overlap threshold of 0.6 used in our implementation ensures reconstruction is only attempted when at least 60\% of states can be reused, avoiding reconstruction overhead when state space changes are large.

We evaluate the cumulative impact of matrix reconstruction on complete FSP simulations by comparing wall-clock times for three benchmark systems. Figure~\ref{fig:speed_comparison} displays the time evolution of computational cost throughout each simulation. Panel (a) presents the Oregonator model, which exhibits sustained chemical oscillations. The standard implementation (dotted line) shows highly variable computational cost with spikes exceeding $10^{-2}$ s per time step during periods of rapid state space expansion, corresponding to oscillation phases where autocatalytic reactions drive the system through transient states. The optimized implementation (solid line) maintains cost below $10^{-3}$ s throughout, with minimal variability. Panel (b) shows the Robertson (ROBER) model, a stiff system with widely separated timescales. The standard method exhibits cost fluctuating between $10^{-3}$ s and $10^{-1}$ s, with pronounced spikes during transient phases. The optimized method reduces cost to approximately $10^{-4}$ s during stable phases, where high state space overlap enables extensive matrix entry reuse. Panel (c) displays the toggle switch model, a bistable system where probability transitions between two stable regions. The standard method (dotted line) shows elevated cost throughout, fluctuating near $10^{0}$ s per time step. The optimized implementation (solid line) reduces cost to below $10^{-1}$ s, with fluctuations between $10^{-2}$ s and $10^{-1}$ s reflecting state space overlap within each basin.

The matrix reconstruction strategy provides substantial computational savings across diverse chemical and biological systems, with performance gains scaling with state space overlap between consecutive time steps. The method adds negligible overhead when overlap is low, ensuring robust performance across the full spectrum of dynamical behaviors in stochastic chemical kinetics.
